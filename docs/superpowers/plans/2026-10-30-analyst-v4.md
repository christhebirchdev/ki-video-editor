# Video-Analyst V4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Engine `v4` neben `v3` mit Aufwand-Trennung, kontextabhängigen Effekten, Neubewertung mit Vorgänger, Nutzer-Historie, Gamification und Integrationsanleitung.

**Architecture:** V4 erbt die V3-Pipeline und verzweigt an `result.engine == "v4"` (wird ab jetzt vor der Bewertung gesetzt). Prompt = V3-Skill + Ersetzungen + Nachsatz. Nutzer/Historie/Level sind kleine eigene Module (`analyst_nutzer.py`, `analyst_fortschritt.py`, `analyst_aufbewahrung.py`) über dem bestehenden Lauf-Verzeichnis. Frontend: bestehende `VideoAnalystPage`, Zusatzblöcke nur bei `engine === "v4"`.

**Tech Stack:** FastAPI, Pydantic 2, Gemini (google-genai), React ohne Build (Babel im Browser), pytest.

Spec: `docs/superpowers/specs/2026-10-30-analyst-v4-design.md`
